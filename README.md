# Направления на МО и ПО

Демонстрационное веб-приложение для подготовки направлений на медицинский и психиатрический осмотры. Использует вымышленную организацию ООО «Ресурс Тест» (РТ) и единый Excel-файл `data/Контингенты_РТ.xlsx` с формами и справочниками. В справочниках 20 должностей из пяти подразделений; для десяти требуется ПО.

## Что работает

Пользователь выбирает подразделение и должность, заполняет сведения кандидата и скачивает направления в Excel и PDF. Анкета кандидата в PDF разбирается непосредственно в браузере посредством локально поставляемого PDF.js; исходный PDF не отправляется на сервер. При создании направления заполненные сведения отправляются серверу и сохраняются вместе с готовыми файлами в архиве пользователя.

Сервер: FastAPI, SQLite для учётных записей и архива, openpyxl для заполнения Excel, LibreOffice для преобразования в PDF. Интерфейс: HTML, CSS и JavaScript без внешнего CDN. База и архив создаются в `storage/` при запуске. Эта папка не входит в исходный код.

Роли `user`, `editor`, `admin` служат примером разграничения прав. Все могут создавать и скачивать свои документы. Редактор и администратор управляют справочником; администратор создаёт приглашения и управляет пользователями. Для внедрения в конкретной организации роли и правила следует согласовать с её требованиями.

## Локальный запуск

Нужны Python 3.12+, LibreOffice (`soffice` в `PATH`) и доступ к PyPI для установки библиотек. Если LibreOffice установлен отдельно, задайте `SOFFICE_BIN` с путём к исполняемому файлу.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

Приложение откроется на `http://127.0.0.1:8100` или следующем свободном порту. На macOS можно дважды нажать `start.command`: он создаст окружение при первом запуске. При первом входе создайте администратора, затем при необходимости пригласите других пользователей. Для демонстрационной подписи пользователя подойдёт `samples/Подпись_крестик.png`.

## Серверный запуск

Пример конфигурации Linux находится в `deploy/`: установка Python-зависимостей, служба systemd и обратный прокси Nginx. Сначала настройте пользователя службы, рабочую папку и адрес сайта под свою среду. Команда приложения: `.venv/bin/python -m uvicorn medflow.main:app --host 127.0.0.1 --port 8000`. Каталог `storage/` должен быть доступен для записи службе и сохраняться при обновлении кода. Первый администратор создаётся через интерфейс до предоставления доступа к сайту.

Для проверки выполните `.venv/bin/python -m pytest -q`. Тесты создают временную базу и направления, не используют `storage/` работающего приложения. Для создания PDF нужен LibreOffice.

## Состав исходников

`medflow/` — API, права доступа, каталог, хранение и генерация документов; `static/` и `templates/` — интерфейс и обработка анкеты в браузере; `data/` — демонстрационный Excel; `tests/` — проверки основных сценариев; `deploy/` — примеры установки. Лицензия поставляемого PDF.js указана в `static/vendor/pdfjs/LICENSE`, сведения о версии — в его `README.md`.

Текущий демонстрационный стенд работает по HTTP. Для эксплуатации с пользовательскими и медицинскими данными требуется согласованная настройка HTTPS и инфраструктурных средств защиты.
